## 2. Kiến trúc Hệ thống Tổng quan (System Architecture)

Để tối ưu hóa chi phí (Cost-efficiency) cho việc xử lý 5 triệu+ dữ liệu, dự án áp dụng mô hình **"Heavy Local - Light Server"**:

### A. Môi trường Local (Xử lý nặng - Heavy Local)
Đây là "Nhà máy" xử lý dữ liệu đặt tại máy tính/mạng cá nhân, chạy 24/7 mà không tốn phí thuê server.
*   **Database:** SQLite (Lưu trữ dữ liệu sạch Gold trong `kigyou-list.db` và dữ liệu thô từ các Crawler dưới dạng các file `.db` độc lập như `hellowork.db` để tránh khóa file).
*   **Data Ingestion:** Python Scripts (Xử lý CSV/JSON từ G-Biz) + Python Crawlers (Yahoo, HelloWork, Official Web) chạy đa luồng qua proxy.
*   **Data Consolidation:** Script ETL chạy ngầm hợp nhất dữ liệu từ các file thô sang database chính `kigyou-list.db`.

### B. Môi trường Server (Phục vụ nhẹ - Light Server)
Đây là "Cửa hàng" đặt trên Cloud/VPS giá rẻ, chỉ tiếp nhận Dữ liệu sạch và phục vụ người dùng.
*   **Database:** Turso / SQLite (Cơ sở dữ liệu đám mây phân tán dựa trên SQLite siêu rẻ hoặc file SQLite tĩnh – Chỉ chứa Bảng chính Gold Data).
*   **Search Engine:** Meilisearch hoặc Typesense (Phục vụ truy vấn siêu tốc và Faceted search trên UI, nhẹ và rẻ hơn Elasticsearch).
*   **Frontend:** Framework hỗ trợ SSR/SSG như Next.js hoặc Astro (Đảm bảo Core Web Vitals < 1s cho SEO).
*   **Cơ chế đồng bộ (Sync):** Local sẽ tự động kết nối qua API hoặc Database Connection để đẩy (`Upsert`) dữ liệu sạch lên Server định kỳ.
