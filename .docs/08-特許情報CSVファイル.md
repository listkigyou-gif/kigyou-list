# 特許情報CSVファイル

3 か月前 更新
このページでは、ダウンロード ページ にて提供している、Gビズインフォに登録されている特許情報を収録したCSVファイルの定義を示します。

※「キー情報」以降の項目は、ファイル ダウンロード時に [メタデータを出力する] を選択した場合にのみ出力されます。

| 通番 | 項目名 | データ型 | 説明 | 備考 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 法人番号 | String | 法人番号の指定を受けた者（以下「法人番号保有者」という。）の法人番号を示すデータ項目。 | |
| 2 | 商号または名称 | String | 法人基本情報の商号又は名称。 | |
| 3 | 登記住所 | String | 法人基本情報の本社所在地。 | |
| 4 | 特許/意匠/商標 | String | 特許データの場合には、値「特許」を出力する。<br>意匠データの場合には、値「意匠」を出力する。<br>商標データの場合には、値「商標」を出力する。 | |
| 5 | 登録番号 | String | 特許情報の登録番号。 | |
| 6 | 出願年月日 | String | 特許情報の出願年月日。 | |
| 7 | 特許_FI分類_コード値 | String | 特許情報の分類種別を示すコード値。<br>特許データの場合のみ値が出力される。 | |
| 8 | 特許_FI分類_コード値（日本語） | String | 「特許_FI分類_コード値」に対応する名称を出力する。<br>特許データの場合のみ値が出力される。 | コード値については<br>こちらを参照 |
| 9 | 特許_Fターム-テーマコード | String | 特許情報のFターム-テーマコードを示すコード値。<br>特許データの場合のみ値が出力される。<br>Fターム-テーマコードの詳細については、以下のURＩ※（特許庁/Fタームテーマコード一覧情報（テーマコード表）：<br>http://www.jpo.go.jp/shiryou/s_sonota/themecode.htm）を参照のこと。 | |
| 10 | 意匠_意匠新分類_コード値 | String | 特許情報の分類種別を示すコード値。<br>商標特許データの場合のみ値が出力される。 | |
| 11 | 意匠_意匠新分類_コード値(日本語) | String | 「商標_類_コード値」に対応する名称を出力する。<br>商標データの場合のみ値が出力される。 | コード値については<br>こちらを参照 |
| 12 | 商標_類_コード値 | String | 特許情報の分類種別を示すコード値。<br>商標特許データの場合のみ値が出力される。 | |
| 13 | 商標_類_コード値(日本語) | String | 「商標_類_コード値」に対応する名称を出力する。<br>商標データの場合のみ値が出力される。 | コード値については<br>こちらを参照 |
| 14 | 発明の名称(等)/意匠に係る物品/表示用商標 | String | 特許データの場合には、発明の名称を出力する。<br>意匠データの場合には、意匠に関わる物品を出力する。<br>商標データの場合には、表示用商標を出力する。 | |
| 15 | 文献固定アドレス | String | 「J-PlatPat」で提供される、特定の文献（特許、実用新案、意匠、商標など）にアクセスするためのURLである。<br>※将来的に提供を開始予定の項目であり、現在は空。 | |
