# 補助金情報CSVファイル

3 か月前 更新
このページでは、ダウンロード ページ にて提供している、Gビズインフォに登録されている補助金情報を収録したCSVファイルの定義を示します。

※「キー情報」以降の項目は、ファイル ダウンロード時に [メタデータを出力する] を選択した場合にのみ出力されます。

| 通番 | 項目名 | データ型 | 説明 | 備考 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 法人番号 | String | 法人番号の指定を受けた者（以下「法人番号保有者」という。）の法人番号を示すデータ項目。 | |
| 2 | 商号または名称 | String | 法人基本情報の商号又は名称。 | |
| 3 | 登記住所 | String | 法人基本情報の本社所在地。 | |
| 4 | 証明日 | String | 補助金情報の認定日。 | |
| 5 | 名称 | String | 補助金情報の活動名称。 | |
| 6 | 金額 | String | 補助金情報の活動金額。 | |
| 7 | 対象 | String | 補助金情報の対象。 | |
| 8 | 発行元 | String | 補助金情報の公表組織。 | |
