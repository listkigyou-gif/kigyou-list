# 財務情報CSVファイル

3 か月前 更新
このページでは、ダウンロード ページ にて提供している、Gビズインフォに登録されている財務情報を収録したCSVファイルの定義を示します。

※「キー情報」以降の項目は、ファイル ダウンロード時に [メタデータを出力する] を選択した場合にのみ出力されます。

| 通番 | 項目名 | データ型 | 説明 | 備考 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 法人番号 | String | 法人番号の指定を受けた者（以下「法人番号保有者」という。）の法人番号を示すデータ項目。 | |
| 2 | 商号または名称 | String | 法人基本情報の商号又は名称。 | |
| 3 | 登記住所 | String | 法人基本情報の本社所在地。 | |
| 4 | 会計基準 | String | 財務情報の会計基準。 | |
| 5 | 事業年度 | String | 財務情報の事業年度。 | |
| 6 | 回次 | String | 財務情報の回次。 | |
| 7 | 売上高 | String | 財務情報の売上高。 | |
| 8 | 売上高（単位) | String | 財務情報の売上高の単位。 | |
| 9 | 営業収益 | String | 財務情報の営業収益。 | |
| 10 | 営業収益（単位） | String | 財務情報の営業収益の単位。 | |
| 11 | 営業収入 | String | 財務情報の営業収入。 | |
| 12 | 営業収入（単位） | String | 財務情報の営業収入の単位。 | |
| 13 | 営業総収入 | String | 財務情報の営業総収入。 | |
| 14 | 営業総収入（単位） | String | 財務情報の営業総収入の単位。 | |
| 15 | 経常収益 | String | 財務情報の経常収益。 | |
| 16 | 経常収益（単位） | String | 財務情報の経常収益の単位。 | |
| 17 | 正味収入保険料 | String | 財務情報の正味収入保険料。 | |
| 18 | 正味収入保険料（単位） | String | 財務情報の正味収入保険料の単位。 | |
